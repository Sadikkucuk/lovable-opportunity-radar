7. AUTOMATIC GITHUB → SUPABASE SYNC
==================================================

Implement a secure server-side synchronization path.

Preferred implementation inside this Lovable/Supabase project:

Create a Supabase Edge Function named something like:

sync-github-ideas

The Edge Function must:

1. Fetch:
https://raw.githubusercontent.com/Sadikkucuk/lovable-opportunity-radar/main/state/idea_catalog.json

2. Validate:
- schema_version
- canonical_key exists
- scope_tier is valid
- lovable_credits_total <= 500
- external_cash_cost = 0

3. Upsert each idea into public.ideas using:
canonical_key

4. Never overwrite these admin-owned fields during sync:
- is_deleted
- deleted_at
- deleted_by

This is critical:
if an admin deletes an idea from the website, the next GitHub sync must NOT make it visible again.

5. For an existing canonical_key:
update its content fields from GitHub but preserve its admin deletion state.

6. For a new canonical_key:
insert a new published idea automatically.

7. Do NOT require approval.

8. If a source_system='github_radar' row exists in Supabase but no longer exists in the GitHub catalog, archive it rather than publicly displaying stale content:
status='archived'
Do not change is_deleted.

9. Never expose Supabase service-role credentials in frontend/client code.

10. Log failures server-side without exposing secrets.

10. ADMIN DELETE PERMISSION
==================================================

Only admin user(s) may delete/hide ideas.

Public/normal users:
- can read published ideas
- cannot insert ideas
- cannot update ideas
- cannot delete ideas

Admin:
- sees a "Sil" action
- deletion requires a confirmation dialog
- deletion must be implemented as SOFT DELETE:

is_deleted = true
deleted_at = now()
deleted_by = auth.uid()

Do not physically remove the row.

Reason:
GitHub remains the canonical catalog and a hard delete would cause the next sync to recreate the idea.

Public queries must always exclude:
is_deleted = true

A deleted idea must disappear immediately from:
- home page
- search
- scope filters
- idea detail routes
- counts

If a user manually tries to open a deleted idea URL, show Not Found / unavailable.
